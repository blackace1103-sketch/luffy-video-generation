# 🎬 AI Video Generator

An open-source web application that transforms simple text prompts into fully assembled videos with scriptwriting, AI-generated visuals, and synthesized voiceovers.

---

## 🌟 Features

* **Scripting:** Automatically breaks down text prompts into storyboard scenes using LLMs.
* **AI Visual Generation:** Renders high-quality video clips for each scene using hosted AI video models.
* **Audio Synthesis:** Generates realistic voiceover narration synced to the script.
* **Automated Video Stitching:** Merges clips, audio, and subtitles into an `.mp4` video.
* **Interactive UI:** Real-time generation progress tracking and built-in video player.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (React), Tailwind CSS
* **Backend:** Python (FastAPI), FFmpeg / Remotion
* **AI Services:** OpenAI / Claude (Scripting), Replicate API / Fal.ai (Video Generation), ElevenLabs (Voiceovers)
* **Database & Auth:** Supabase / PostgreSQL
